# 정답 없이 '내가 틀렸는지' 알 수 있나 — 문헌 정리 (2026-11-26)

물음 (사용자, 후속 75): 전체 카메라 · 선반 카메라 · 센서를 함께 쓰는 까닭은 하나가 틀릴 때를 막으려는 것인데,
각 출처는 정답지 없이 자기가 틀렸는지 알 수 있나? 다른 연구자들은 어떻게 풀었나?

표시: **[열어 봄]** = 조사 에이전트가 논문 · 특허 페이지를 열어 제목 · 저자 · 내용을 확인함. **[색인만]** = 출판사 · 색인 기록으로만 확인 (본문 못 엶).
**[미확인]** = 확인 못 함. 내가 한 편씩 다시 열어 본 것은 아니다 — 인용하기 전에 링크를 직접 확인할 것.

## 1. 한 줄 답

| 출처 수 | 정답 없이 알 수 있는 것 | 못 하는 것 |
|---|---|---|
| 1개 (혼자) | 자기 점수, 장면 사이 흔들림(종류가 바뀜 · 순간이동), 앞뒤로 따라가 본 차이 | 일관되게 틀린 것. 점수가 높아도 틀린다 |
| 2개 | **서로 다르다**는 것 | **누가** 틀렸는지 |
| 3개 이상 · 서로 독립 | 다수결로 하나를 가려냄. 출처마다의 오류율도 추정 | 같이 틀리는 것 (공통 원인) |
| + 물리 제약 | 제약을 어기면 누군가 틀렸다는 **증명** | 제약을 안 어기는 오류 |
| + 늦게 오는 정답 | 오류율을 직접 잼, 문턱 · 믿음 값을 맞춤 | 그 정답이 오기 전의 판단 |

곁가지 (합치기 · 개수 가리기는 없음): MERL Shopping Dataset (Singh 외, CVPR 2016), ShopMiner (Shangguan 외, SenSys 2015, RFID),

조사 논문 Rukundo 외 (arXiv:2503.07997). 못 찾은 것: Zippin · Trigo · AiFi 의 기술 논문, 가방 숨김 + 개수 세기 논문, 숨겼다 다시 보인 물건을 잇는 논문.

**되풀이되는 설계**
1. **개수의 기준은 무게, 종류의 기준은 자리(칸), 영상은 '누가'.** Grab 말고는 모두 무게 사건에서 시작한다.
2. 오류는 **출처 사이의 모순**으로 잡는다 (배운 믿음 점수가 아니다): 사람 없는 무게 사건 버림 · 방향이 반대인 가설 지움 · 자리가 안 맞으면 믿음 낮춤 · 놓음은 든 것 안에서만.
3. 믿음은 1등과 2등 가설의 차. 낮으면 센서를 더 넣고 → 이웃 사건과 합치고 → **사람이 본다** → 그 답으로 다시 가르친다.
4. 매장을 문제에 맞춘다: 칸 하나에 상품 하나, 칸막이, 날마다 채움.

**아무도 못 푼 것**: 서로 다를 때 정답 없이 사건마다 가리기 (학계는 믿음 출력이 없고 업계는 사람 검토로 끝난다), 다른 상품을 동시에 집기,
건넴 · 일행, 선반을 떠난 뒤의 일 (가방 · 주머니 · 다시 보임 — 개수는 선반 사건에서 정해지고 다시 안 본다), 출처 셋 (카메라 둘 + 무게) 사이의 가리기.
모든 정확도 수치는 사람이 붙인 정답으로 쟀다 — 돌아가는 동안의 자기 오류율을 재는 논문은 없었다.

## 3. 일반 이론 — 정답 없이 오류를 아는 법

### 3-1. 일치 · 불일치만으로 오류율 추정
- Dawid · Skene 1979, JRSS-C 28(1) [열어 봄] https://ideas.repec.org/a/bla/jorssc/v28y1979i1p20-28.html — 참값을 숨은 변수로 두고 관찰자마다 혼동 행렬을 EM 으로 추정. 조건: 참값이 주어지면 오류가 서로 독립.
- Hui · Walter 1980, Biometrics 36(1) [열어 봄] — 검사 **둘**은 한 집단에서는 못 푼다. 유병률이 다른 **두 집단**이 있으면 풀린다.
- Platanios · Blum · Mitchell 2014, UAI [열어 봄] https://proceedings.mlr.press/r12/university14g.html — 분류기들의 일치율에서 오류율을 되찾음.
- Platanios 외 2017, NeurIPS [열어 봄] https://arxiv.org/abs/1705.07086 — 출력 사이의 **논리 제약**(동시에 참일 수 없음)을 더함: 제약 위반 = 누군가 틀림.
- Parisi 외 2014, PNAS 111(4) [열어 봄] https://arxiv.org/abs/1303.3257 — 독립이면 예측 공분산이 1차 구조 → 고유벡터가 정확도 순위.
- Jaffe 외 [열어 봄] https://arxiv.org/abs/1407.7644 , https://arxiv.org/abs/1510.05830 — 뒤 논문: **독립이 깨지면 이 방법들이 크게 나빠진다**. 서로 기대는 묶음을 먼저 찾자.
- Ratner 외 2016 · 2017 (Data Programming · Snorkel) [열어 봄] https://arxiv.org/abs/1605.07723 , Fu 외 2020 (FlyingSquid, ICML) [열어 봄] https://proceedings.mlr.press/v119/fu20a.html — 겹침과 충돌에서 출처별 정확도를 배움 (셋씩 묶어 닫힌 식).
- 공통 한계: 조건부 독립 · 우연보다 나은 출처 · 보통 셋 이상. **같이 틀리는 출처는 '정확한 출처'처럼 보인다.**

### 3-2. 정답 없이 성능 어림 (분포가 바뀔 때)
- Garg 외 2022, ICLR (ATC) [열어 봄] https://arxiv.org/abs/2201.04234 · Guillory 외 2021, ICCV (DoC) [열어 봄] https://arxiv.org/abs/2107.03315 · Jiang 외 2022, ICLR [열어 봄] · Baek 외 2022, NeurIPS [열어 봄] https://arxiv.org/abs/2206.13089
- Kirsch · Gal 2022, TMLR [열어 봄] https://arxiv.org/abs/2202.01851 — 불일치가 커지는 곳에서 보정이 무너지고, 보정을 확인하려면 정답이 든다.
- 한계: 전체 평균 정확도의 어림이지 사건마다의 '틀림' 표시가 아니다. Garg 는 일반적으로는 불가능하다고 적었다.

### 3-3. 모델 하나의 불확실성
- Guo 외 2017, ICML (보정) [열어 봄] https://arxiv.org/abs/1706.04599 · Lakshminarayanan 외 2017 (앙상블) [열어 봄] https://arxiv.org/abs/1612.01474 · Gal · Ghahramani 2016 (MC dropout) [열어 봄] https://arxiv.org/abs/1506.02142 · Hendrycks · Gimpel 2017 [열어 봄] https://arxiv.org/abs/1610.02136 · Geifman · El-Yaniv 2017 (거절 선택) [열어 봄] · Angelopoulos · Bates (conformal) [열어 봄] https://arxiv.org/abs/2107.07511
- 알려진 한계 — **자신 있게 틀린다**: Hein 외 2019, CVPR [열어 봄] https://arxiv.org/abs/1812.05720 (배운 것과 먼 입력에 높은 점수), Ovadia 외 2019, NeurIPS [열어 봄] https://arxiv.org/abs/1906.02530 (분포가 바뀌면 보정이 안 버팀, 앙상블이 가장 나음). 보정 · conformal 의 보장은 같은 분포의 정답이 있어야 한다.

### 3-4. 돌아가는 동안의 일관성 검사
- Kang · Raghavan · Bailis · Zaharia 2020, MLSys — "Model Assertions" [열어 봄] https://arxiv.org/abs/2003.01668 — 사람이 쓴 규칙으로 출력을 검사 (예: 영상에서 물체의 종류가 빠르게 바뀜). 쓴 규칙의 오류만 잡고, 걸려도 어느 출력이 틀렸는지는 안 알려 준다.
- Kalal · Mikolajczyk · Matas 2010, ICPR — Forward-Backward Error [색인만] — 앞으로 따라간 뒤 거꾸로 따라가 처음 자리와의 차이로 추적 실패를 안다.
- Rahman · Corke · Dayoub 2021, IEEE Access [열어 봄] https://arxiv.org/abs/2101.01364 — 로봇 인식의 실행 중 감시 조사 논문.

### 3-5. 고전 다중 센서 고장 검출
- Willsky 1976, Automatica 12(6) [열어 봄] · Isermann 1984 · Gertler 1988 [색인만] — 해석적 중복: 모델로 잔차를 내고 무늬로 고장 난 센서를 가림. 한계: 모델 오류와 센서 고장이 안 갈린다.
- Lyons · Vanderkulk 1962 (3중 다수결) [색인만] — 독립인 고장 하나를 가림.
- **Knight · Leveson 1986, IEEE TSE 12(1)** [열어 봄] — 따로 만든 판본들도 **독립으로 틀리지 않았다**. 공통 원인 고장의 대표 결과.
- Lamport · Shostak · Pease 1982 (비잔틴) [열어 봄] — 제멋대로 틀리는 m 개를 견디려면 3m + 1 개.
- Marzullo 1990 · Brooks · Iyengar 1996 [색인만 / 열어 봄] — 구간 겹침. 틀린 센서가 N/3 미만이어야.
- Parkinson · Axelrad 1988 (RAIM) [색인만] — **남는 측정 하나면 '틀림'을 알고, 둘이면 '누가'를 안다** (위성 5개 → 검출, 6개 → 제외).
- Julier · Uhlmann 1997 (공분산 교차) [색인만] — 상관을 몰라도 과신하지 않게 합침. 고장을 찾지는 않는다.
- Zadeh 1986 [색인만] — Dempster-Shafer 합침은 충돌을 정규화로 지워 엉뚱한 확신을 낼 수 있다.
- Narasimhan · Jordache 1999, Data Reconciliation and Gross Error Detection [색인만] — **질량 보존 제약**이 측정을 중복으로 만들어 큰 오류를 찾게 한다.

### 3-6. 자율주행 인식의 자기 검사
- Antonante · Spivak · Carlone [열어 봄] https://arxiv.org/abs/2011.07010 , https://arxiv.org/abs/2205.10906 — 모듈 · 시간 사이 일관성 검사를 그래프로 두고 '고장 몇 개까지 가려낼 수 있나'의 한계를 증명 (시뮬레이션).
- Matos 외 2024, Sensors 24(16):5108 [열어 봄] — 카메라와 라이다는 안개 · 비에서 **함께** 나빠진다 (공통 원인).

| 사람 없는 센서 사건 버림 | 방문과 못 묶은 센서는 선반 앞 사람에게 | — |
| 모순인 가설 지우기 | — | 한 카메라의 '선반 밖(버림)'이 다른 카메라의 '집음'을 못 막는다 (4차 N03) |
| 믿음 = 가설 차, 낮으면 사람 검토 | '확인 필요' 판정은 있음 | **출처가 갈린 방문**을 표시해 확인 필요로 보내는 길이 없다 (한계 E-17) |
| 3개 다수결 | 센서 · 선반 지도 · 전체 카메라 개수 셋이 방문마다 적힘 | 다수결을 안 쓴다. 써도 S1 은 틀린다 (센서와 전체 카메라가 같이 놓침) |
| 늦게 오는 정답으로 오류율 재기 | 결제 로그 | 결제와 맞는 출처 · 안 맞는 출처를 세는 통계가 없다 |
| 일관성 규칙 (Model Assertions) | — | '놓음 직후 다시 집음' · '줄이 건너뜀' · '종류가 바뀜'을 경고로 안 쓴다 |
| 공통 원인 줄이기 | 센서는 카메라와 원인이 다름 | 두 카메라가 **같은 상품 모델**을 쓴다 — 소지품을 둘 다 동과루로 읽었다 (N03) |

같은 날 4차 · 3차에서 본 '세 출처의 말' (방문 한 번, 동과루 · 칸타타):

| 영상 | 정답 | 센서 | 선반 지도 | 전체 카메라 개수 | 다수결 | 지금 규칙 (max) |
|---|---|---|---|---|---|---|
| 4차 N04 동과루 | 1 | 1 | **2** | 1 | 1 ✓ | 2 ✗ (경보) |
| 3차 T05 동과루 | 3 | **0** | 3 | 3 | 3 ✓ | 3 ✓ |
| 4차 S1 칸타타 | 1 | **0** | 1 | **0** | 0 ✗ | 1 ✓ |
| 4차 T05 동과루 | 3 | 3 | 3 | **2** | 3 ✓ | 3 ✓ |

규칙을 '센서만'으로 바꾸면 (`fusion.sensor_kind_rule=sensor`, 2026-11-26 실험, 기준은 안 바꿈): 4차 센서 + 결제 40 → 40 (N04 맞음, S1 틀림), 3차 37 → 36 (T05 틀림).
어느 한 출처를 늘 믿는 규칙은 없다 — 문헌의 결론과 같다.
