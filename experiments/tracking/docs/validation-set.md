# 검증 영상 세트 — 무엇을 어떤 영상으로 검증하나

## 집중할 세 가지 (팀 결정, 2026-10-06)

1. **사람 추적** — 들어와서 나갈 때까지 같은 사람으로 따라가기
2. **집기 감지** — 사람이 물건을 집는지·되돌려놓는지
3. **선반 물건 식별 → 개수** — 선반 위 물건을 알아보고, 그 정보로 사람이 몇 개를 가졌는지 판단

세 가지는 필요한 영상 조건이 다르다. 사람 추적에는 사람이 크게 보이면 되지만, 물건 개수에는 **선반 위 물건이 하나씩 또렷해야** 한다.
그래서 기능마다 고르는 기준을 따로 정하고, 가진 영상을 모두 같은 잣대로 재서 나눴다.

## 고르는 기준

| 기능 | 꼭 필요한 것 | 있으면 좋은 것 | 정답 |
|---|---|---|---|
| 사람 추적 | 모델 입력 속 사람 키 **90px 이상**(65px 미만 제외, `scale-limits.md`), 여러 사람 | 겹침·가림·화면 밖으로 나갔다 들어옴 | 사람 수, 번호가 바뀐 순간 (눈으로 확인) |
| 집기 감지 | 손과 선반이 함께 보임, 실제 집는 장면 | 우리 매장과 같은 카메라 각도, 되돌려놓기 | 집기·되돌려놓기 시각 (라벨 또는 눈으로) |
| 선반 물건 개수 | 선반 정면이 보임, 물건 **3개 이상이 하나씩** 탐지됨, 물건 크기 **32px 이상**(모델 입력 기준, 원본보다 크게 치지 않음) | 한 줄 진열·띄워 놓음, 같은 종류 여러 개, 되돌려놓기, 두 사람 | 언제 어느 자리에서 몇 개가 빠졌고/다시 놓였고, 누가 했는지 |
| 개수 세기 통합 | 위 '선반 물건' + 사람이 선반에 닿는 장면 | 출구·계산대 | 손님별 최종 개수 |

## 자동 거름망 — `scripts/screen_videos.py`

영상마다 고르게 뽑은 장면(기본 24장)에서 사람 크기, **자리 잡은 물건**(장면 절반 이상 같은 자리에 탐지된 것) 수와 크기,
사람이 물건 영역에 닿은 장면 비율을 재고 1차 등급을 매긴다. 영상마다 확인용 사진(물건 초록, 사람 파랑)도 만든다.

**숫자만 믿으면 안 된다 — 최종 선정은 사진을 보고 사람이 한다.** 실제로 확인해 보니:
- UCF-Crime 에서 '자리 잡은 물건'으로 잡힌 것은 **진열 상품이 아니라 가구·기기**였다
  (의자, 키보드, 모니터, 오토바이, 여행가방 — 이름은 suitcase·motorcycle·keyboard·train 등). 선반의 상품은 너무 작고 빽빽해 하나씩 잡히지 않는다.
- MERL 은 선반의 상품 상자 묶음을 'book'(106편 중 79편)으로 크게 잡는다. 상자 하나하나가 아니다.
- Pexels 10566656 은 사람 눈에는 물건이 또렷한데(가까이서 찍은 흰 병들) 일반 YOLO 가 하나도 잡지 못했다.

만들면서 고친 것: 처음엔 작은 영상(320x240)을 모델 크기로 키운 값으로 재서 UCF 물건이 4배 크게 나왔다(9px → 35px).
키워 넣어도 정보는 늘지 않으므로 원본 해상도까지만 친다. 또 MPEG2 녹화본은 프레임 수를 17로 알려 처음 0.7초만 봤다 — 직접 센다.

## 빈 곳 — 가진 영상으로 채울 수 없는 것

| 검증할 것 | 왜 없나 |
|---|---|
| 한 번에 2개 이상 가져감 | 세 편 모두 1개씩 |
| 가져갔다가 **다른 자리에** 되돌려놓기 | 들었다 같은 자리에 놓는 장면뿐 |
| 구경만 하고 떠남 (선반 앞에 섰지만 아무것도 안 바뀜) | 없음 |
| **두 사람이 같은 선반에** (동시 / 차례로) | 없음 — 누구 것인지 정하는 규칙이 시험된 적 없음 |
| 같은 종류 여러 개 중 하나 | 없음 |
| 가방·주머니에 숨기기 | 바구니에 넣는 것 하나뿐 |
| 우리 매장 카메라 각도·조명 | 카메라 미정 (`limitations.md` B-1) |

공개 데이터 조사(`limitations.md` 부록)에서도 이런 영상은 없었다. **직접 촬영으로만 채울 수 있다.**

### 촬영할 선반 장면 (제안)

> 2026-10-07: 이 장면들은 출구·계산대 장면과 합쳐 `filming-guide.md` 5절(S-B·S-C)로 옮겼다. 아래는 처음 제안 그대로 둔다.

준비: 카메라 고정, 선반 정면과 사람 전신이 함께 보이게. 물건은 한 줄로, 물건 폭의 절반 이상 띄워서.
물건 크기는 모델 입력에서 32px 이상 — 1920x1080 촬영이면 원본에서 약 48px 이상(물건 탐지 해상도 1280 기준).
배경과 색이 구별되는 물건(흰 벽 앞 흰 병은 피함, 10566656 실패 참고).

| # | 장면 | 정답으로 적을 것 |
|---|---|---|
| S-1 | 한 명이 1개 가져감 | 시각, 자리, 사람 |
| S-2 | 한 번에 2개 가져감 | 개수 2 |
| S-3 | 가져갔다가 제자리에 되돌려놓음 | 순 개수 0 |
| S-4 | 가져갔다가 다른 자리에 놓음 | 빠진 자리, 생긴 자리 |
| S-5 | 선반 앞에서 구경만 하고 떠남 | 개수 0 |
| S-6 | 같은 종류 3개 중 가운데 1개 | 몇 번째인지 |
| S-7 | 두 사람이 차례로 각자 1개 | 사람별 1개 |
| S-8 | 두 사람이 동시에 선반 앞, 한 명만 가져감 | 누가 가져갔는지 |
| S-9 | 가져가서 가방에 넣고 출구로 | 개수 1, 미결제 |
| S-10 | 가져가서 계산대에서 결제 후 출구로 | 개수 1, 결제 1 → 통과 |

S-9·S-10 은 기존 촬영 계획(`filming-guide.md`)의 출구·계산대 장면과 함께 찍으면 위험 판정까지 한 번에 검증된다.
