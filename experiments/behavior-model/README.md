# behavior-model — 행동 인식 모델 학습·테스트

담당: 정준우

AI-Hub의 **무인 매장 정상 행동 및 이상 행동 데이터**로 모델을 학습시키고,
정상 행동과 이상 행동을 얼마나 정확하게 구분하는지 시험한다.
좋은 결과가 나오면 `final/` 통합 단계에서 추적 파이프라인과 연결한다.

## 데이터 준비

1. AI-Hub에서 데이터 이용 신청 후 내려받는다.
2. `data/aihub/` 아래에 둔다.

`data/`와 `aihub/` 폴더는 `.gitignore`로 막혀 있어 **커밋되지 않는다.**
AI-Hub 약관상 원본과 가공본 모두 재배포할 수 없으므로 이 규칙을 지운 채로 커밋하지 않는다.

## 폴더 구성 (권장)

```
behavior-model/
├─ data/          # 데이터 (커밋 안 됨)
├─ src/           # 전처리·학습·평가 코드
├─ configs/       # 학습 설정
├─ notebooks/     # 탐색용 노트북
└─ README.md
```
