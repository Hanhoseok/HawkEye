## 6. 정상 영상 — 시간당 오경보

**미측정** — 이 데이터셋에는 정상 영상이 없다.

측정하려면 정상 영상을 모아 다음을 실행한다.

```powershell
python -m storeguard.data.add_normal --dir <정상영상폴더>
python -m storeguard.data.preprocess --workers 4
python -m storeguard.evaluate --run unified_r2p1d --split normal
```
