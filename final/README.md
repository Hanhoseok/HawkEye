# final — 최종 통합 시스템

각 실험 폴더에서 비교해 **선택된 방법만** 가져와 최종 시스템을 만드는 곳이다.
아직 비어 있다.

## 통합 방식

1. 실험 폴더에서 방법을 비교한다 (각 README의 "실험 기록" 참고).
2. 적중률이 가장 좋은 조합을 팀이 함께 정한다.
3. 선택된 코드를 이 폴더로 옮겨 정리한다. 실험용 코드는 가져오지 않는다.
4. 이 폴더에 들어가는 PR은 다른 팀원 1명 이상이 확인한 뒤 머지한다.

## 예상 구성

| 부분 | 가져올 곳 |
|---|---|
| 영상 입력 · 사람/상품 탐지 · 추적 | `experiments/tracking/` |
| 행동 인식 모델 | `experiments/behavior-model/` |
| 결제 대조 · 출구 위험 판정 | `experiments/tracking/` + `experiments/app-pos/` (모의 결제) |
| 관리자 앱 · 알림 | `experiments/app-pos/` |
